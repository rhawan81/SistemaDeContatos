📒 Sistema de Gerenciamento de Contatos
Sistema de gerenciamento de contatos desenvolvido em Java, executado via console. O projeto permite adicionar, listar, buscar, editar e excluir contatos, praticando os fundamentos de Programação Orientada a Objetos (POO).

📋 Funcionalidades

✅ Adicionar novo contato (nome, telefone e email)
✅ Listar todos os contatos cadastrados
✅ Buscar contato pelo nome
✅ Editar telefone e email de um contato existente
✅ Excluir contato pelo nome


🛠 Tecnologias utilizadas

Java 17+
IntelliJ IDEA
Git / GitHub


📁 Estrutura do projeto
SistemaContatos/
└── src/
└── br/com/contatos/
├── modelo/
│   └── Contato.java              # Classe que representa um contato
├── gerenciador/
│   └── GerenciadorContatos.java # Lógica de gerenciamento da lista
└── Main.java                     # Ponto de entrada e menu do sistema

▶️ Como rodar o projeto
Pré-requisitos

Java 17 ou superior instalado
IntelliJ IDEA (ou outra IDE Java)

Passos

Clone o repositório:

bashgit clone https://github.com/rhawan81/SistemaContatos.git

Abra o projeto no IntelliJ IDEA
Execute o arquivo Main.java
Interaja com o menu no console:

===== Sistema de Contatos =====
1. Adicionar Contato
2. Listar Contatos
3. Buscar Contato
4. Excluir Contato
5. Editar Contato
0. Sair

💡 Conceitos praticados

Programação Orientada a Objetos (POO)
Encapsulamento com private, getters e setters
ArrayList para armazenamento dinâmico de objetos
Scanner para leitura de dados no console
Estruturas de controle: while, switch, if/else
Organização de código em pacotes
